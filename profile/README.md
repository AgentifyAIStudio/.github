## ⭐ Selected Case Studies

### 1. Production-Grade Multi-Agent Platform

**Challenge**

A company with more than 100 employees wanted to automate routine work across six departments using AI agents.

The agents needed to interact with CRM, accounting and telephony systems while operating continuously and preserving task state even during infrastructure failures.

**Solution**

A reusable multi-agent platform was designed with a custom execution engine and durable workflow architecture.

Key capabilities:

- persistent agent state
- checkpoint-based recovery
- automatic continuation after failures
- integrations with enterprise systems
- distributed deployment
- scalable agent execution

**Results**

- **15 AI agents running in production**
- **200,000+ agent cycles per month**
- infrastructure failures without loss of task context
- reusable architecture suitable for deployment across multiple clients

**Technology**

`Python` · `Temporal` · `PostgreSQL` · `pgvector` · `Kubernetes` · `LLM APIs` · `Local LLMs`

---

### 2. Enterprise RAG Knowledge Assistant

**Challenge**

A company had accumulated several thousand technical documents, manuals, specifications and regulations.

Sales teams often spent 15–20 minutes finding technical information, while more difficult questions had to be escalated to engineers.

**Solution**

A knowledge assistant was developed over the company's technical documentation.

The system combines:

- semantic search
- exact-match retrieval
- embeddings
- hybrid retrieval
- reranking
- source-level citations
- evaluation based on real user questions

Special attention was given to technical content containing part numbers, tables and numeric parameters that standard semantic search can miss.

**Results**

- information retrieval time reduced from **15–20 minutes to approximately 1 minute**
- approximately **85% correct answers** on the evaluation dataset
- engineering escalations reduced by approximately **50%**
- the assistant explicitly reports when reliable information cannot be found instead of inventing an answer

**Technology**

`LangGraph` · `PostgreSQL` · `pgvector` · `Embeddings` · `LLM APIs` · `RAG`

### 3. AI Incident Intelligence Assistant

**Challenge**

Operational teams often need to collect information from multiple service events before they can understand an incident and determine possible causes.

Manual analysis can be slow and dependent on individual expert knowledge.

**Solution**

An AI-assisted incident analysis application was designed to:

- capture service events
- combine related events into incidents
- build structured incident context
- generate probable root-cause hypotheses
- estimate confidence
- recommend next actions
- indicate when manual expert review is required

The goal is not to replace engineers, but to accelerate investigation and provide structured decision support.

**Core capabilities**

`Incident Aggregation` · `LLM Diagnostics` · `Root Cause Analysis` · `Confidence Scoring` · `Human-in-the-Loop`

---

### 4. AI Sales Copilot with Measured Business Impact

**Challenge**

The objective was to determine whether an AI agent could create measurable sales impact rather than simply assist employees.

**Solution**

An AI sales assistant was developed to identify potential upsell opportunities using customer information.

The solution included:

- AI-generated recommendations
- tool calling
- regression testing for new agent versions
- automated response evaluation
- LLM-as-judge evaluation
- gradual rollout
- human approval for critical actions

**Results**

During a two-month pilot:

- revenue per participating salesperson increased by approximately **13–17% compared with the comparison group**

The pilot group was voluntary, so the result is treated as an upper-bound indication rather than a guaranteed effect.

**Technology**

`LLM APIs` · `Tool Calling` · `AI Evals` · `LLM-as-Judge` · `Human-in-the-Loop`

## 🧠 Our Approach to Production AI

Building an impressive AI demo is relatively easy.

Building an AI system that works reliably inside a real company is much harder.

We focus on the engineering challenges that matter in production:

### Reliability

Agent workflows should survive failures and resume safely.

### Evaluation

AI quality should be measured using repeatable tests rather than subjective impressions.

### Grounding

Enterprise assistants should use verified company knowledge and provide sources whenever possible.

### Human Control

High-impact or sensitive actions should remain under appropriate human supervision.

### Integration

AI systems need to work with existing databases, APIs, CRMs, knowledge bases and enterprise applications.

### Business Value

Every project should start with a clear business problem and measurable success criteria.
